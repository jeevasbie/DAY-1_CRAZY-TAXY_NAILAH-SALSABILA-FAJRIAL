Apa itu Repository? Repository (sering disingkat repo) adalah wadah digital atau tempat penyimpanan terpusat yang digunakan untuk menyimpan file, berkas, kode program, hingga dokumentasi suatu proyek secara terstruktur.
Tujuan Utama Repository? Tujuan utama pembuatan repository ini adalah sebagai sarana dokumentasi resmi seluruh kegiatan dan materi selama berlangsungnya kegiatan workshop.
Kegunaan Repository? kegunaan dari repository ini adalah untuk mencatat riwayat perubahan data (version control), mengamankan materi dan hasil pembelajaran agar mudah diakses kembali, serta menjadi wadah publikasi portofolio karya.
